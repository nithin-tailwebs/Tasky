# Tasky React UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the React front end for Tasky — login, boards, a draggable kanban board, card editing, comments and My Tasks — against the finished API in `docs/api.md`.

**Architecture:** A Vite + React app in `frontend/`, plain JavaScript, Tailwind for styling. Server data comes from `fetch` wrapped in a shared `apiFetch` client plus per-resource hooks; there is no data library and no global store. The one piece of genuine complexity — optimistic drag-and-drop with rollback — is isolated in `src/state/moveCard.js` as a pure function with the network call injected, which is what makes it testable without simulating a drag. In development Vite proxies `/api` to Django so the browser sees a single origin; in production Django serves the built files.

**Tech Stack:** React 19, Vite, React Router, `dnd-kit`, Tailwind CSS v4, Vitest.

## Global Constraints

- **Plain JavaScript.** No TypeScript, no `.ts`/`.tsx` files.
- **No data-fetching library.** No TanStack Query, no SWR, no Redux, no Zustand.
- **No CORS.** Never add `django-cors-headers`. Same-origin is achieved by the Vite proxy in dev and by Django serving the build in prod.
- **Statuses are exactly** `todo`, `in_progress`, `done`.
- **Priority is an integer** — `1` Low, `2` Medium, `3` High. Responses also carry `priority_label`; it is read-only.
- **`position` is opaque.** Never assume it is contiguous, never assume `index === position`, never treat a gap as corruption.
- **Never send `status` or `board` in a card PATCH.** Column moves go only through `POST /api/cards/{id}/move/`.
- **Unauthenticated calls return `403`, never `401`.**
- **All `fetch` calls use `credentials: "same-origin"`** so the session cookie travels.
- **Frontend** tests are Vitest only, and only for `src/api/client.js` and `src/state/moveCard.js`. No component tests, no dnd-kit simulation. This does not restrict backend pytest tests — Task 8 adds one by design.
- `frontend/dist/` is gitignored (Task 1), but Task 8 force-adds a single `.gitkeep` inside it so `STATICFILES_DIRS` resolves on a clean clone. That is deliberate, not an oversight.
- Commit after every task.

```js
// frontend/src/api/client.js
export class ApiError extends Error {
  constructor(status, data) {
    super(`API error ${status}`)
    this.name = 'ApiError'
    this.status = status
    this.data = data
  }
}

export class SessionExpiredError extends ApiError {
  constructor(status, data) {
    super(status, data)
    this.name = 'SessionExpiredError'
  }
}

export function getCookie(name) {
  const match = document.cookie.match(new RegExp('(^|;\\s*)' + name + '=([^;]*)'))
  return match ? decodeURIComponent(match[2]) : null
}

async function parseBody(res) {
  try {
    return await res.json()
  } catch {
    return null
  }
}

export async function apiFetch(path, { method = 'GET', body } = {}) {
  const headers = {}
  if (body !== undefined) headers['Content-Type'] = 'application/json'
  if (method !== 'GET') {
    const token = getCookie('csrftoken')
    if (token) headers['X-CSRFToken'] = token
  }

  const res = await fetch(path, {
    method,
    headers,
    credentials: 'same-origin',
    body: body !== undefined ? JSON.stringify(body) : undefined,
  })

  if (res.status === 204) return null
  if (res.ok) return parseBody(res)

  const data = await parseBody(res)

  if (res.status === 403) {
    // 403 is ambiguous: an expired session, or a legitimate permission denial
    // such as deleting someone else's comment. Raw fetch, not apiFetch — an
    // apiFetch here would recurse forever once the session is genuinely gone.
    const me = await fetch('/api/auth/me/', { credentials: 'same-origin' })
    if (me.status === 403) throw new SessionExpiredError(403, data)
    throw new ApiError(403, data)
  }

  throw new ApiError(res.status, data)
}
```

```jsx
// frontend/src/hooks/useFetch.js
import { useCallback, useEffect, useState } from 'react'

export function useFetch(fn, deps = []) {
  const [data, setData] = useState(null)
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  const run = useCallback(() => {
    setLoading(true)
    setError(null)
    return fn()
      .then((result) => { setData(result); return result })
      .catch((err) => { setError(err); throw err })
      .finally(() => setLoading(false))
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, deps)

  useEffect(() => { run().catch(() => {}) }, [run])

  return { data, loading, error, refetch: run }
}
```

- [ ] **Step 1: Write the auth context**

Nothing renders until `booting` is false, so no screen flashes before the user is known. A 403 from `/me/` means "not signed in" — the API never returns 401.

```jsx
// frontend/src/auth/AuthContext.jsx
import { createContext, useContext, useEffect, useState } from 'react'
import { getCsrf, getMe, login as apiLogin, logout as apiLogout } from '../api/auth'

const AuthContext = createContext(null)

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null)
  const [booting, setBooting] = useState(true)

  useEffect(() => {
    let cancelled = false
    async function boot() {
      try {
        await getCsrf()
        const me = await getMe()
        if (!cancelled) setUser(me)
      } catch {
        if (!cancelled) setUser(null)   // 403 === not signed in
      } finally {
        if (!cancelled) setBooting(false)
      }
    }
    boot()
    return () => { cancelled = true }
  }, [])

  async function signIn(username, password) {
    const me = await apiLogin(username, password)
    setUser(me)
    return me
  }

  async function signOut() {
    await apiLogout()
    setUser(null)
  }

  return (
    <AuthContext.Provider value={{ user, booting, signIn, signOut }}>
      {children}
    </AuthContext.Provider>
  )
}

export function useAuth() {
  const ctx = useContext(AuthContext)
  if (!ctx) throw new Error('useAuth must be used inside AuthProvider')
  return ctx
}
```

```jsx
// frontend/src/routes/Login.jsx
import { useState } from 'react'
import { useAuth } from '../auth/AuthContext'

export default function Login() {
  const { signIn } = useAuth()
  const [username, setUsername] = useState('')
  const [password, setPassword] = useState('')
  const [error, setError] = useState(null)
  const [busy, setBusy] = useState(false)

  async function onSubmit(e) {
    e.preventDefault()
    setBusy(true)
    setError(null)
    try {
      await signIn(username, password)
    } catch (err) {
      setError(err.data?.detail ?? 'Could not sign in. Try again.')
    } finally {
      setBusy(false)
    }
  }

  return (
    <div className="min-h-screen grid place-items-center bg-slate-50">
      <form onSubmit={onSubmit} className="w-80 space-y-4 rounded-lg bg-white p-6 shadow">
        <h1 className="text-xl font-semibold">Sign in to Tasky</h1>
        <input
          className="w-full rounded border px-3 py-2"
          placeholder="Username" value={username} autoFocus
          onChange={(e) => setUsername(e.target.value)}
        />
        <input
          className="w-full rounded border px-3 py-2" type="password"
          placeholder="Password" value={password}
          onChange={(e) => setPassword(e.target.value)}
        />
        {error && <p className="text-sm text-red-600">{error}</p>}
        <button
          className="w-full rounded bg-slate-900 py-2 text-white disabled:opacity-50"
          disabled={busy}
        >
          {busy ? 'Signing in…' : 'Sign in'}
        </button>
      </form>
    </div>
  )
}
```

```jsx
// frontend/src/routes/Boards.jsx
import { useState } from 'react'
import { Link } from 'react-router-dom'
import Layout from '../components/Layout'
import { useFetch } from '../hooks/useFetch'
import { listBoards, createBoard } from '../api/boards'

export default function Boards() {
  const { data: boards, loading, error, refetch } = useFetch(listBoards, [])
  const [name, setName] = useState('')
  const [creating, setCreating] = useState(false)

  async function onCreate(e) {
    e.preventDefault()
    if (!name.trim()) return
    setCreating(true)
    try {
      await createBoard({ name: name.trim() })
      setName('')
      await refetch()
    } finally {
      setCreating(false)
    }
  }

  return (
    <Layout>
      <div className="mx-auto max-w-3xl space-y-6">
        <form onSubmit={onCreate} className="flex gap-2">
          <input
            className="flex-1 rounded border px-3 py-2" placeholder="New board name"
            value={name} onChange={(e) => setName(e.target.value)}
          />
          <button className="rounded bg-slate-900 px-4 text-white disabled:opacity-50" disabled={creating}>
            Add board
          </button>
        </form>

        {loading && <p className="text-slate-500">Loading boards…</p>}
        {error && (
          <p className="text-red-600">
            Could not load boards. <button onClick={refetch} className="underline">Retry</button>
```

```js
export const STATUSES = ['todo', 'in_progress', 'done']

export const STATUS_LABELS = {
  todo: 'To Do',
  in_progress: 'In Progress',
  done: 'Done',
}

// GET /api/boards/{id}/cards/ interleaves all three statuses in one
// position-ordered list, so the client groups it. Two cards in different
// columns sharing a position is expected, not corruption.
export function groupByStatus(cards) {
  const buckets = { todo: [], in_progress: [], done: [] }
  for (const c of cards ?? []) {
    if (buckets[c.status]) buckets[c.status].push(c)
  }
  return buckets
}
```

- [ ] **Step 4: Write `moveCard.js`**

```js
// frontend/src/state/moveCard.js
import { STATUSES } from './buckets'

function findCard(buckets, cardId) {
  for (const status of STATUSES) {
    const card = buckets[status].find((c) => c.id === cardId)
    if (card) return { card, from: status }
  }
  return { card: null, from: null }
}

export function removeCard(buckets, cardId) {
  const next = {}
  for (const status of STATUSES) {
    next[status] = buckets[status].filter((c) => c.id !== cardId)
  }
  return next
}

// Remove from the source column BEFORE inserting into the destination.
// Doing it the other way round is off by one whenever a card moves down
// within its own column.
export function applyMove(buckets, cardId, toStatus, toIndex) {
  const { card } = findCard(buckets, cardId)
  if (!card) return buckets

  const next = removeCard(buckets, cardId)
  const moved = { ...card, status: toStatus }
  const target = [...next[toStatus]]
  target.splice(toIndex, 0, moved)
  next[toStatus] = target
  return next
}

export async function moveCard({ buckets, cardId, toStatus, toIndex, setBuckets, postMove, refetch }) {
  const snapshot = buckets
  setBuckets(applyMove(buckets, cardId, toStatus, toIndex))

  try {
    await postMove(cardId, { status: toStatus, position: toIndex })
    // The server renumbers the whole column inside a transaction. If someone
    // else dragged concurrently our local guess is wrong, so reconcile.
    await refetch()
  } catch (err) {
    if (err.status === 404) {
      // Deleted before the move landed — drop it rather than resurrect it.
      setBuckets(removeCard(snapshot, cardId))
      await refetch()
      return
    }
    setBuckets(snapshot)
    throw err
  }
}
```

`handleDragEnd` resolves where the card landed — dropping onto a column drops onto its id, dropping onto a card drops onto that card's id — then delegates every state decision to `moveCard`.

```jsx
// frontend/src/routes/Board.jsx
import { useCallback, useEffect, useState } from 'react'
import { useParams } from 'react-router-dom'
import { DndContext, closestCorners, PointerSensor, useSensor, useSensors } from '@dnd-kit/core'
import Layout from '../components/Layout'
import Column from '../components/Column'
import { getBoard, getBoardCards } from '../api/boards'
import { createCard, postMove } from '../api/cards'
import { groupByStatus, STATUSES } from '../state/buckets'
import { moveCard } from '../state/moveCard'

const EMPTY = { todo: [], in_progress: [], done: [] }

export default function Board() {
  const { id } = useParams()
  const [board, setBoard] = useState(null)
  const [buckets, setBuckets] = useState(EMPTY)
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  const load = useCallback(async () => {
    const [b, cards] = await Promise.all([getBoard(id), getBoardCards(id)])
    setBoard(b)
    setBuckets(groupByStatus(cards))
  }, [id])

  useEffect(() => {
    setLoading(true)
    load().catch(setError).finally(() => setLoading(false))
  }, [load])

  const sensors = useSensors(useSensor(PointerSensor, { activationConstraint: { distance: 4 } }))

  function locate(overId) {
    if (STATUSES.includes(overId)) return { status: overId, index: buckets[overId].length }
    for (const status of STATUSES) {
      const index = buckets[status].findIndex((c) => c.id === overId)
      if (index !== -1) return { status, index }
    }
    return null
  }

  async function handleDragEnd({ active, over }) {
    if (!over) return
    const target = locate(over.id)
    if (!target) return
    try {
      await moveCard({
        buckets, cardId: active.id,
        toStatus: target.status, toIndex: target.index,
        setBuckets, postMove, refetch: load,
      })
    } catch (err) {
      setError(err)
    }
  }

  async function handleAdd(status, title) {
    // status is allowed on CREATE — it is only PATCH that rejects a change.
    await createCard({ board: Number(id), title, status })
    await load()
  }

  if (loading) return <Layout><p className="text-slate-500">Loading board…</p></Layout>

  return (
    <Layout>
      <div className="mb-4">
        <h1 className="text-lg font-semibold">{board?.name}</h1>
        {board?.description && <p className="text-sm text-slate-500">{board.description}</p>}
      </div>

      {error && (
        <p className="mb-3 text-red-600">
          Something went wrong. <button onClick={() => { setError(null); load() }} className="underline">Retry</button>
        </p>
      )}

      <DndContext sensors={sensors} collisionDetection={closestCorners} onDragEnd={handleDragEnd}>
        <div className="flex gap-4 overflow-x-auto pb-4">
          {STATUSES.map((s) => (
            <Column key={s} status={s} cards={buckets[s]} onAdd={handleAdd} />
          ))}
        </div>
      </DndContext>
    </Layout>
  )
}
```

## Task 10: Comments

**Files:**
- Create: `frontend/src/components/CommentThread.jsx`

**Interfaces:**
- Consumes: `listComments`, `createComment`, `deleteComment`, `useAuth`, `useFetch`
- Produces: `<CommentThread cardId>`

- [ ] **Step 1: Write the thread**

Delete is author-only server-side, returning 403 otherwise. `client.js` already distinguishes that from an expired session, so a rejected delete surfaces as a message and does not sign the user out. The button is hidden for non-authors anyway; the guard is for the race where the rule changes underneath.

```jsx
// frontend/src/components/CommentThread.jsx
import { useCallback, useState } from 'react'
import { useFetch } from '../hooks/useFetch'
import { useAuth } from '../auth/AuthContext'
import { listComments, createComment, deleteComment } from '../api/comments'

export default function CommentThread({ cardId }) {
  const { user } = useAuth()
  const fetcher = useCallback(() => listComments(cardId), [cardId])
  const { data: comments, refetch } = useFetch(fetcher, [cardId])
  const [body, setBody] = useState('')
  const [error, setError] = useState(null)

  async function add(e) {
    e.preventDefault()
    if (!body.trim()) return
    try {
      await createComment(cardId, body.trim())
      setBody('')
      await refetch()
    } catch {
      setError('Could not post the comment.')
    }
  }

  async function remove(id) {
    try {
      await deleteComment(id)
      await refetch()
    } catch (err) {
      setError(err.status === 403 ? 'You can only delete your own comments.' : 'Could not delete.')
    }
  }

  return (
    <div className="border-t pt-3">
      <h3 className="mb-2 text-sm font-semibold text-slate-700">Comments</h3>
      {error && <p className="mb-2 text-sm text-red-600">{error}</p>}

      <ul className="mb-3 space-y-2">
        {(comments ?? []).map((c) => (
          <li key={c.id} className="rounded bg-slate-50 p-2 text-sm">
            <div className="flex items-center gap-2">
              <span className="font-medium">{c.author?.display_name || c.author?.username || 'Deleted user'}</span>
              <span className="text-xs text-slate-400">{c.created_at.slice(0, 10)}</span>
              {(!c.author || c.author.id === user?.id) && (
                <button onClick={() => remove(c.id)} className="ml-auto text-xs text-red-600">Delete</button>
              )}
            </div>
            <p className="mt-1 whitespace-pre-wrap">{c.body}</p>
          </li>
        ))}
      </ul>

      <form onSubmit={add} className="flex gap-2">
        <input className="flex-1 rounded border px-2 py-1 text-sm" placeholder="Write a comment…"
               value={body} onChange={(e) => setBody(e.target.value)} />
        <button className="rounded border px-3 py-1 text-sm">Post</button>
      </form>
    </div>
  )
}
```
